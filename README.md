# DocHarvest

A Python command-line tool for downloading documentation pages
and saving readable text as a structured dataset.

## Planned features

- Fetch pages from a list of URLs
- Extract titles and readable text
- Save results as JSONL
- Download concurrently with controlled request rates
- Handle temporary failures with retries
- Respect robots.txt
- Include automated tests

## Learning goal

Build this project and understand the design decisions
behind HTTP fetching, concurrency, testing, and Python packaging.
